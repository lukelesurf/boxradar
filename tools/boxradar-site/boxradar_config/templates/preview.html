The selection drawn at the panel's real geometry — 320×240, the same projection, the same marker shapes, the same colours after 8-bit quantisation. Shown at each range the scope offers, because crowding is a property of the scale rather than of the selection: a set of labels that is unreadable at 50nm can be perfectly clear at 10.

Traffic is not drawn, and that is the one place this is not faithful. Aircraft datablocks are placed by an occupancy grid in the firmware and a second copy of it here would drift. Fixed references have no such mechanism — the firmware puts every label at a flat five pixels right and three up, and moves nothing out of the way — so an overlap below is an overlap on the shelf. {% if not has_coast %} The coastline is not drawn: it has not been fetched for this home yet, and the preview never goes to the network.
