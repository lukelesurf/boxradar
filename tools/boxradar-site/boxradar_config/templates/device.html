Saved on board means the value is stored in the board's NVS, which overrides whatever is compiled into the firmware — permanently and silently, so a later change to config.h for that setting would appear to do nothing. Ticking use built-in default removes the stored value so the compiled one takes over again.

The board restarts to apply changes, so the scope goes dark for a few seconds.
