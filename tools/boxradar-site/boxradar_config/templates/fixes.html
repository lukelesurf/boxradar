Two sources in one list, because they are the same thing to you and only differ in where they come from. Navaids — the 3-letter VOR/NDB/DME idents — are downloaded. Enroute fixes — 5-letter RNAV points like LOREL — are published only in the NATS eAIP ENR 4.4 table and appear in no free dataset, so the whole published table ships with the application — all ~1000 of them, extracted from that page. Their notes say which procedures each one belongs to, so searching for EGSS finds the fixes on Stansted procedures rather than needing you to know their names.
