# Receiver Installer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One resumable script that provisions a BOXRADAR receiver from a bare Raspberry Pi OS Lite install — readsb, tar1090, both feeders, and the boxradar services — so the existing receiver can be rebuilt and a second unit built by someone else.

**Architecture:** A thin driver (`tools/receiver-install/install.sh`) collects site configuration once into `/etc/boxradar/receiver.conf`, then runs six numbered stage scripts that each read that file and are independently idempotent. Config file contents are generated by pure shell functions in `lib/render.sh`, which are unit-tested from Python without a Pi. One change lands outside the installer: METAR runway headings become derived from OurAirports data rather than hand-written.

**Tech Stack:** Bash (`set -euo pipefail`, shellcheck-clean), Python 3.11 stdlib + shapely/PyYAML/Flask from apt, systemd, unittest.

## Global Constraints

- **Nothing comes from pip.** Debian's Python is externally managed under PEP 668. Every Python dependency must exist as a `python3-*` package on bookworm. Allowed: `shapely`, `yaml`, `flask`, `jinja2`.
- **`boxradar_site` service modules stay stdlib-only.** `metar.py`, `cache.py`, `server.py`, `upstream.py`, `config.py`, `contacts.py`, `feed.py`, `__main__.py`, `__init__.py` must not import shapely, yaml, flask, jinja2, `boxradar_site.geo`, or `boxradar_config`. Enforced by `tests/test_dependency_boundary.py`. **All new derivation code goes in `boxradar_config`,** which may import `boxradar_site` (established: `store.py`, `fixes.py`, `app.py` all do).
- **Python floor is 3.7**, per the existing `tools/boxradar-site/install.sh` check. The Pi runs 3.11.2.
- **Target platform:** `aarch64` only. ARMv6/ARMv7 boards cannot run FR24's binary (`Tag_CPU_arch: v7`). RAM floor 1 GB (coastline reduction peaks at 367 MB).
- **Test command**, from repo root:
  `python3 -m unittest discover -s tools/boxradar-site/tests -t tools/boxradar-site -v`
  Baseline before this plan: **414 tests, OK.**
- **Shell:** every `.sh` passes `shellcheck`. Stages run under `set -euo pipefail`.
- **Secrets** (`FR24_KEY`, `ADSBX_UUID`) never enter git, never appear in logs. `receiver.conf` is 0600 root-owned; only `receiver.conf.example` is tracked.
- **Commits:** conventional (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).
- Shapely is 2.x in the Nix devShell and 1.8 on the Pi. Geometry assertions compare with tolerance, never equality.

```python
"""METAR runway headings, derived from runway thresholds.

/etc/boxradar-site/config.json used to be written by hand: a designator and a
TRUE heading per runway end, read by metar.pick_runway() to choose the active
runway from the wind. Sourcing those for an unfamiliar airport means reading
the AIP, and mistaking magnetic for true gives a wrong answer with no visible
error — not a reasonable thing to ask of someone setting up a second unit.

The axis is the one datasets.runways() already returns for drawing
centrelines, under the rule its docstring states: published headings sometimes
disagree with their own threshold coordinates by more than a degree, so the
coordinates win. Checked against the table curated by hand for EGSS, EGGW and
EGMC — all three agree, including EGSS 04, where the dataset publishes 44 and
the thresholds give 43.
"""

import math

from . import datasets


def bearing(lat0, lon0, lat1, lon1):
    """Initial true bearing from the first point to the second, 0-360."""
    phi0, phi1 = math.radians(lat0), math.radians(lat1)
    dlon = math.radians(lon1 - lon0)
    y = math.sin(dlon) * math.cos(phi1)
    x = (math.cos(phi0) * math.sin(phi1)
         - math.sin(phi0) * math.cos(phi1) * math.cos(dlon))
    return (math.degrees(math.atan2(y, x)) + 360.0) % 360.0


def metar_runways(cache_dir, icao):
    """[(designator, true heading), ...] for one station, both ends of each.

    Ordered as the dataset gives them — longest runway first, since
    datasets.runways() sorts that way and the longest is the one most likely
    to be in use.
    """
    out = []
    for runway in datasets.runways(cache_dir, [icao]):
        low, _, high = runway.ident.partition("/")
        heading = bearing(runway.lat0, runway.lon0, runway.lat1, runway.lon1)
        if low and low != "?":
            out.append((low, int(round(heading)) % 360))
        if high and high != "?":
            out.append((high, int(round(heading + 180.0)) % 360))
    return out
```

```python
def site_config(cache_dir, icao, calm_kt=None):
    """The /etc/boxradar-site/config.json document for one station.

    A station with no runways in the dataset still yields a valid document.
    pick_runway() degrades to no-runway on an empty table, and wind, cloud and
    visibility do not depend on it.
    """
    calm = DEFAULT_CALM_KT if calm_kt is None else int(calm_kt)
    pairs = metar_runways(cache_dir, icao)
    table = {icao.upper(): [[d, h] for d, h in pairs]} if pairs else {}
    return {"runways": table, "calm_kt": calm}


def write_site_config(path, cache_dir, icao, calm_kt=None):
    """Write the document, atomically. Returns what was written."""
    doc = site_config(cache_dir, icao, calm_kt)
    path = pathlib.Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    # Same directory so the rename is atomic: boxradar-site reads this file at
    # startup, and a half-written one would be ignored as unparseable.
    tmp = path.with_suffix(path.suffix + ".part")
    tmp.write_text(json.dumps(doc, indent=2) + "\n")
    tmp.replace(path)
    return doc
```

"""Config rendering for the receiver installer.

The renderers are pure functions of receiver.conf, so they are testable
without a Pi. This is the layer that closes the position drift found on the
hand-built receiver, where readsb, the ADSBExchange feeder and selection.json
each carried a slightly different home position.
"""

import os
import pathlib
import subprocess
import unittest

RENDER_SH = (pathlib.Path(__file__).resolve().parents[3]
             / "receiver-install" / "lib" / "render.sh")

BASE = {"LAT": "51.8849826", "LON": "0.2349914", "ALT_FT": "348",
        "GAIN": "auto", "PPM": "0", "ADSBX_USER": "example-feeder",
        "ADSBX_UUID": "test-uuid-1234", "FR24_KEY": "testkey9876"}


def render(function, **overrides):
    env = dict(os.environ)
    env.update(BASE)
    env.update(overrides)
    result = subprocess.run(
        ["bash", "-c", f'set -euo pipefail; source "{RENDER_SH}"; {function}'],
        env=env, capture_output=True, text=True)
    if result.returncode != 0:
        raise AssertionError(f"{function} failed: {result.stderr}")
    return result.stdout


class TestRenderReadsb(unittest.TestCase):
    def test_position_comes_from_the_conf(self):
        out = render("render_readsb")
        self.assertIn("--lat 51.8849826", out)
        self.assertIn("--lon 0.2349914", out)

    def test_mlat_return_port_is_present(self):
        # Without 30104 in --net-bi-port, mlat-client has nowhere to return
        # results and MLAT positions silently vanish.
        self.assertIn("--net-bi-port 30004,30104", render("render_readsb"))

    def test_gain_and_ppm_come_from_the_conf(self):
        out = render("render_readsb", GAIN="49.6", PPM="-2")
        self.assertIn("--gain 49.6", out)
        self.assertIn("--ppm -2", out)

    def test_every_expected_variable_is_defined(self):
        out = render("render_readsb")
        for key in ("RECEIVER_OPTIONS", "DECODER_OPTIONS", "NET_OPTIONS",
                    "JSON_OPTIONS"):
            self.assertIn(f"{key}=", out)

    def test_output_is_valid_shell(self):
        # /etc/default/readsb is sourced by systemd's EnvironmentFile.
        out = render("render_readsb")
        subprocess.run(["bash", "-n"], input=out, text=True, check=True)

```bash
#!/usr/bin/env bash
# Config file renderers. Each writes a complete file to stdout and reads its
# values from the environment, which install.sh populates from receiver.conf.
#
# Rendering to stdout rather than to a path is deliberate: it makes every
# generated file assertable from tests/test_receiver_render.py without a Pi,
# and it keeps the decision about *where* a file lands in the stage that owns
# it. Nothing here writes to stderr — stages tee stdout to a log, and a key on
# stderr would end up in it.

render_readsb() {
  cat <<EOF
# Generated by tools/receiver-install. Edits are lost on the next run —
# change /etc/boxradar/receiver.conf and re-run install.sh instead.
RECEIVER_OPTIONS="--device 0 --device-type rtlsdr --gain ${GAIN} --ppm ${PPM}"
DECODER_OPTIONS="--lat ${LAT} --lon ${LON} --max-range 450 --write-json-every 1"
NET_OPTIONS="--net --net-ri-port 30001 --net-ro-port 30002 --net-sbs-port 30003 --net-bi-port 30004,30104 --net-bo-port 30005 --net-ro-size=8192 --net-json-port=12345 --net-json-port-interval=0.5"
JSON_OPTIONS="--json-location-accuracy 2 --range-outline-hours 24 --db-file=/usr/local/share/tar1090/aircraft.csv.gz --db-file-lt"
EOF
}

# 30104 in --net-bi-port above is load-bearing: adsbexchange-mlat returns its
# results to 127.0.0.1:30104, and without that port readsb never accepts them.
# Dropping it does not fail loudly — MLAT aircraft just stop appearing.

render_adsbexchange() {
  cat <<EOF
# Generated by tools/receiver-install. See /etc/boxradar/receiver.conf.
INPUT=""
REDUCE_INTERVAL="0.5"
USER="${ADSBX_USER}"
LATITUDE="${LAT}"
LONGITUDE="${LON}"
ALTITUDE="${ALT_FT}ft"
UAT_INPUT=""
RESULTS="--results beast,connect,127.0.0.1:30104"
RESULTS2="--results basestation,listen,31003"
RESULTS3="--results beast,listen,30157"
RESULTS4="--results beast,connect,127.0.0.1:30154"
PRIVACY=""
INPUT_TYPE="dump1090"
MLATSERVER="feed.adsbexchange.com:31090"
TARGET="--net-connector feed1.adsbexchange.com,30004,beast_reduce_out,feed2.adsbexchange.com,64004"
NET_OPTIONS="--net --net-heartbeat 60 --net-ro-size 1280 --net-ro-interval 0.2 --net-ro-port 0 --net-sbs-port 0 --net-bi-port 30154 --net-bo-port 0 --net-ri-port 0"
JSON_OPTIONS="--json-location-accuracy 2 --range-outline-hours 24"
EOF
}

render_fr24() {
  cat <<EOF
receiver="beast-tcp"
fr24key="${FR24_KEY}"
bs="no"
raw="no"
mlat="yes"
mlat-without-gps="yes"
host="127.0.0.1:30005"
EOF
}

#!/usr/bin/env bash
# receiver.conf: the single source of truth for a site.
#
# Validation is stricter than it looks like it needs to be because the person
# running this on the second unit cannot be assumed to notice a transposed
# coordinate — and a wrong position does not show up on the display. It
# degrades MLAT, quietly.

conf_number() { [[ $1 =~ ^-?[0-9]+([.][0-9]+)?$ ]]; }
conf_integer() { [[ $1 =~ ^-?[0-9]+$ ]]; }

conf_validate() {
  local problems=0
  _bad() { echo "receiver.conf: $*" >&2; problems=1; }

  [[ -n ${HOSTNAME:-} ]] || _bad "HOSTNAME is empty"
  [[ ${HOSTNAME:-} =~ ^[a-z0-9][a-z0-9-]*$ ]] || \
    _bad "HOSTNAME must be lowercase letters, digits and hyphens"

  if ! conf_number "${LAT:-}"; then
    _bad "LAT is not a number: '${LAT:-}'"
  elif (( $(echo "${LAT} > 90 || ${LAT} < -90" | bc -l) )); then
    _bad "LAT out of range: ${LAT}"
  fi

  if ! conf_number "${LON:-}"; then
    _bad "LON is not a number: '${LON:-}'"
  elif (( $(echo "${LON} > 180 || ${LON} < -180" | bc -l) )); then
    _bad "LON out of range: ${LON}"
  fi

  conf_integer "${ALT_FT:-}" || \
    _bad "ALT_FT must be a whole number of feet: '${ALT_FT:-}'"
  [[ ${GAIN:-} == "auto" ]] || conf_number "${GAIN:-}" || \
    _bad "GAIN must be 'auto' or a number: '${GAIN:-}'"
  conf_number "${PPM:-}" || _bad "PPM must be a number: '${PPM:-}'"
  [[ ${METAR_STATION:-} =~ ^[A-Za-z]{4}$ ]] || \
    _bad "METAR_STATION must be a 4-letter ICAO code: '${METAR_STATION:-}'"
  conf_integer "${CALM_KT:-}" || _bad "CALM_KT must be a whole number"
  [[ -n ${ADSBX_USER:-} ]] || _bad "ADSBX_USER is empty"
  [[ -n ${FR24_KEY:-} ]] || _bad "FR24_KEY is empty"

  return $problems
}

conf_write() {
  local path=$1
  mkdir -p "$(dirname "$path")"
  # Created 0600 before anything is written to it: the file carries the FR24
  # key and the ADSBExchange uuid, and a default-umask window is still a
  # window.
  install -m 0600 /dev/null "$path"
  cat >"$path" <<EOF
# BOXRADAR receiver configuration. Written by tools/receiver-install.
# Mode 0600 — this file carries feeder credentials. Never commit it.

# Identity
HOSTNAME=${HOSTNAME}

# Position. ONE source, fanned out to readsb, ADSBExchange, MLAT and
# selection.json. The hand-built receiver carried four different positions
# spanning ~15m; MLAT is the consumer for which that was not cosmetic.
LAT=${LAT}
LON=${LON}
ALT_FT=${ALT_FT}

# Radio
GAIN=${GAIN}
PPM=${PPM}

# Network. Blank STATIC_IP means DHCP.
STATIC_IP=${STATIC_IP}

# Weather
METAR_STATION=${METAR_STATION}
CALM_KT=${CALM_KT}

# Feeder identity. Restored on reinstall so statistics and MLAT peer
# reputation survive a rebuild rather than starting from zero.
ADSBX_USER=${ADSBX_USER}
ADSBX_UUID=${ADSBX_UUID}
FR24_KEY=${FR24_KEY}
EOF
}

conf_load() {
  local path=$1
  [[ -r $path ]] || { echo "cannot read $path" >&2; return 1; }
  # shellcheck disable=SC1090
  source "$path"
}
```

"""The installer driver: stage discovery, stamping and resumption.

Stamping is an optimisation, not the correctness mechanism — every stage is
independently idempotent — but resumption is what turns "it died at the FR24
step" into something the second operator can act on, so it is worth testing.
"""

import os
import pathlib
import subprocess
import tempfile
import unittest

INSTALL = (pathlib.Path(__file__).resolve().parents[3]
           / "receiver-install" / "install.sh")


class DriverCase(unittest.TestCase):
    def setUp(self):
        self.dir = tempfile.TemporaryDirectory()
        self.addCleanup(self.dir.cleanup)
        self.root = pathlib.Path(self.dir.name)
        self.stages = self.root / "stages"
        self.stages.mkdir()
        self.stamps = self.root / "stamps"

    def stage(self, name, body="exit 0"):
        path = self.stages / name
        path.write_text(f"#!/usr/bin/env bash\nset -euo pipefail\n{body}\n")
        path.chmod(0o755)

    def run_driver(self, *args):
        env = dict(os.environ)
        env.update({
            "BOXRADAR_STAGE_DIR": str(self.stages),
            "BOXRADAR_STAMP_DIR": str(self.stamps),
            "BOXRADAR_LOG": str(self.root / "install.log"),
            "BOXRADAR_CONF": str(self.root / "receiver.conf"),
            "BOXRADAR_SKIP_ROOT_CHECK": "1",
        })
        return subprocess.run(["bash", str(INSTALL), *args],
                              env=env, capture_output=True, text=True)


class TestStageRunning(DriverCase):
    def test_stages_run_in_numeric_order(self):
        self.stage("10-first.sh", 'echo ran-10')
        self.stage("20-second.sh", 'echo ran-20')
        self.stage("30-third.sh", 'echo ran-30')
        out = self.run_driver("--no-wizard").stdout
        self.assertLess(out.index("ran-10"), out.index("ran-20"))
        self.assertLess(out.index("ran-20"), out.index("ran-30"))

    def test_a_completed_stage_is_stamped(self):
        self.stage("10-first.sh")
        self.run_driver("--no-wizard")
        self.assertTrue((self.stamps / "10-first.done").exists())

    def test_a_stamped_stage_is_skipped_on_rerun(self):
        self.stage("10-first.sh", 'echo ran-10')
        self.run_driver("--no-wizard")
        out = self.run_driver("--no-wizard").stdout
        self.assertNotIn("ran-10", out)
        self.assertIn("skip", out.lower())

    def test_force_reruns_a_stamped_stage(self):
        self.stage("10-first.sh", 'echo ran-10')
        self.run_driver("--no-wizard")
        self.assertIn("ran-10", self.run_driver("--no-wizard", "--force").stdout)

    def test_from_starts_at_the_given_stage(self):
        self.stage("10-first.sh", 'echo ran-10')
        self.stage("20-second.sh", 'echo ran-20')
        out = self.run_driver("--no-wizard", "--from", "20").stdout
        self.assertNotIn("ran-10", out)
        self.assertIn("ran-20", out)

    def test_a_failing_stage_stops_the_run(self):

```bash
#!/usr/bin/env bash
# Provision a BOXRADAR receiver from a bare Raspberry Pi OS Lite install.
#
#   sudo ./install.sh              collect config if needed, then run stages
#   sudo ./install.sh --check      render configs and diff, change nothing
#   sudo ./install.sh --from 40    resume at a stage
#   sudo ./install.sh --force      re-run stages already marked done
#
# Stamping is an optimisation. Every stage is independently idempotent, so
# --force is always safe and a stamp that lies costs repeated work rather than
# a broken box.
set -euo pipefail

SRC_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
STAGE_DIR="${BOXRADAR_STAGE_DIR:-$SRC_DIR/stages}"
STAMP_DIR="${BOXRADAR_STAMP_DIR:-/var/lib/boxradar-install}"
LOG="${BOXRADAR_LOG:-/var/log/boxradar-install.log}"
CONF="${BOXRADAR_CONF:-/etc/boxradar/receiver.conf}"

# shellcheck source=lib/conf.sh
source "$SRC_DIR/lib/conf.sh"
# shellcheck source=lib/render.sh
source "$SRC_DIR/lib/render.sh"

CHECK=0 FORCE=0 FROM=0 WIZARD=1

usage() {
  cat <<'EOF'
usage: sudo ./install.sh [options]

  --check      render every config file and diff against what is live.
               Changes nothing. Run this before rebuilding a working box.
  --from N     resume at stage N (e.g. --from 40)
  --force      re-run stages already marked complete
  --no-wizard  use /etc/boxradar/receiver.conf as-is, prompt for nothing
  --help       this text
EOF
}

while [[ $# -gt 0 ]]; do
  case $1 in
    --check) CHECK=1 ;;
    --force) FORCE=1 ;;
    --from) FROM="$2"; shift ;;
    --no-wizard) WIZARD=0 ;;
    --help|-h) usage; exit 0 ;;
    *) echo "unknown option: $1" >&2; usage >&2; exit 2 ;;
  esac
  shift
done

if [[ ${BOXRADAR_SKIP_ROOT_CHECK:-0} != 1 && $EUID -ne 0 ]]; then
  echo "error: run as root (sudo ./install.sh)" >&2
  exit 1
fi

# Redact before anything is teed. The log is the artefact the second operator
# sends back when something fails, so it must never carry their FR24 key.
redact() {
  local patterns=()
  [[ -n ${FR24_KEY:-} ]] && patterns+=(-e "s|${FR24_KEY}|<FR24_KEY>|g")
  [[ -n ${ADSBX_UUID:-} ]] && patterns+=(-e "s|${ADSBX_UUID}|<ADSBX_UUID>|g")
  if [[ ${#patterns[@]} -eq 0 ]]; then cat; else sed "${patterns[@]}"; fi
}

[[ -r $CONF ]] && conf_load "$CONF"

# The wizard runs BEFORE logging starts, and the order matters. `read -r`
# echoes what is typed, and the FR24 key is typed at a prompt — if the log
# were already capturing this stream, the key would be written to it before
# redact() had any way of knowing the value to redact.
if [[ $WIZARD -eq 1 ]]; then
  run_wizard
  conf_load "$CONF"
fi

mkdir -p "$(dirname "$LOG")" "$STAMP_DIR"
exec > >(redact | tee -a "$LOG") 2>&1

echo "=== boxradar receiver install: $(date -Is) ==="

if ! conf_validate; then
  echo "error: fix $CONF and re-run" >&2
  exit 1
fi

export HOSTNAME LAT LON ALT_FT GAIN PPM STATIC_IP METAR_STATION CALM_KT
export ADSBX_USER ADSBX_UUID FR24_KEY

if [[ $CHECK -eq 1 ]]; then
  check_mode
  exit 0
fi

shopt -s nullglob
for stage in "$STAGE_DIR"/*.sh; do
  name="$(basename "$stage" .sh)"
  number="${name%%-*}"
  stamp="$STAMP_DIR/$name.done"

  if (( 10#$number < 10#$FROM )); then
    echo "--- $name: skipped (--from $FROM)"
    continue
  fi
  if [[ -e $stamp && $FORCE -eq 0 ]]; then
    echo "--- $name: skipped (already complete; --force to re-run)"
    continue
  fi

  echo "--- $name: running"
  if ! bash "$stage"; then
    status=$?
    cat >&2 <<EOF

stage $name failed (exit $status)
completed stages keep their stamps and will be skipped.
fix, then re-run:  sudo ./install.sh
full log:          $LOG
EOF
    exit "$status"
  fi
  touch "$stamp"
  echo "--- $name: complete"
done

echo "=== all stages complete ==="
```

Add the wizard and check-mode functions above the argument parsing:

```bash
ask() {
  # ask VAR "prompt" "default"
  local var=$1 prompt=$2 default=${3:-} reply
  local current="${!var:-$default}"
  if [[ -n $current ]]; then
    read -r -p "$prompt [$current]: " reply || true
    printf -v "$var" '%s' "${reply:-$current}"
  else
    while :; do
      read -r -p "$prompt: " reply || true
      [[ -n $reply ]] && break
      echo "  (required)"
    done
    printf -v "$var" '%s' "$reply"
  fi
}

run_wizard() {
  cat <<'EOF'

Setting up a BOXRADAR receiver. Existing answers are shown in brackets —
press enter to keep one, or type a new value.

EOF
  ask HOSTNAME     "Hostname (reachable as <name>.local)" "boxradar"
  ask LAT          "Aerial latitude, decimal degrees"
  ask LON          "Aerial longitude, decimal degrees"
  ask ALT_FT       "Aerial height above sea level, whole feet"
  ask GAIN         "Tuner gain ('auto' or a number)" "auto"
  ask PPM          "Tuner frequency correction, ppm" "0"
  ask STATIC_IP    "Static IP (blank for DHCP)" " "
  ask METAR_STATION "Nearest airport with a METAR, 4-letter ICAO"
  ask CALM_KT      "Below this windspeed, recommend no runway" "7"
  ask ADSBX_USER   "ADSBExchange feeder name"
  ask ADSBX_UUID   "ADSBExchange uuid (blank on a new box)" " "
  ask FR24_KEY     "Flightradar24 sharing key"
  STATIC_IP="${STATIC_IP// /}"
  ADSBX_UUID="${ADSBX_UUID// /}"
  conf_write "$CONF"
  echo "wrote $CONF (0600)"
}

check_mode() {
  echo "--- rendered /etc/default/readsb"
  render_readsb
  echo "--- rendered /etc/default/adsbexchange"
  render_adsbexchange
  echo "--- rendered /etc/fr24feed.ini (key redacted above)"
  render_fr24
  for pair in "/etc/default/readsb:render_readsb" \
              "/etc/default/adsbexchange:render_adsbexchange"; do
    local live="${pair%%:*}" fn="${pair##*:}"
    if [[ -r $live ]]; then
      echo "--- diff against live $live"
      diff <("$fn") "$live" || true
    fi
  done
}

#!/usr/bin/env bash
# Refuse before anything is touched.
#
# Every check here exists because its absence produces a confusing failure
# later. The architecture check in particular: an ARMv6 board installs FR24's
# armhf package cleanly and then dies with SIGILL on first run, because the
# binary is built Tag_CPU_arch v7. Saying so here beats debugging that.
set -euo pipefail

fail() { echo "preflight: $*" >&2; exit 1; }
warn() { echo "preflight: WARNING: $*"; }

arch="$(uname -m)"
[[ $arch == aarch64 ]] || fail \
  "architecture is $arch, needs aarch64.
   Flightradar24's armhf binary is built for ARMv7 (Tag_CPU_arch v7), so
   ARMv6 boards such as the Pi Zero W cannot feed it at all. Use a 64-bit
   Raspberry Pi OS on a Pi 3, Pi 4 or Pi 5."

mem_mb=$(( $(awk '/MemTotal/ {print $2}' /proc/meminfo) / 1024 ))
(( mem_mb >= 900 )) || fail \
  "only ${mem_mb}MB RAM, needs 1GB.
   Reducing a fresh coastline peaks at 367MB on top of ~182MB of running
   services, which does not fit in 512MB."
(( mem_mb >= 1800 )) || warn \
  "${mem_mb}MB RAM. Enough, but 2GB is comfortable — the first coastline
   build for a new area peaks at 367MB."

lsusb | grep -qiE 'RTL2838|RTL2832|Realtek.*DVB-T' || fail \
  "no RTL-SDR found in lsusb. Plug the dongle in and re-run."

for host in deb.debian.org github.com overpass-api.de; do
  getent hosts "$host" >/dev/null || fail "cannot resolve $host — no internet?"
done

free_gb=$(( $(df --output=avail -k / | tail -1) / 1024 / 1024 ))
(( free_gb >= 8 )) || fail "only ${free_gb}GB free on /, needs 8GB"

if command -v vcgencmd >/dev/null 2>&1; then
  throttled="$(vcgencmd get_throttled 2>/dev/null || echo throttled=0x0)"
  value="${throttled#throttled=}"
  if (( (value & 0x1) || (value & 0x4) )); then
    warn "the board is under-volting right now ($throttled).
   This is a power supply or cable problem, not a software one. It causes
   dropped samples and unexplained reboots. Fix it before trusting anything
   this receiver reports."
  elif (( value & 0x50000 )); then
    warn "under-voltage has occurred since boot ($throttled). Watch the PSU."
  fi
fi

if systemctl is-active --quiet lightdm 2>/dev/null; then
  warn "a desktop session is running. This is meant for Raspberry Pi OS Lite;
   the desktop costs roughly a third of RAM on a 1GB board."
fi

echo "preflight: ${arch}, ${mem_mb}MB RAM, ${free_gb}GB free, SDR present"
```

**Interfaces:**

- Produces: hostname set, persistent journal, ufw enabled, unattended-upgrades configured, wifi power-save disabled.

- [ ] **Step 1: Write the stage**

```bash
#!/usr/bin/env bash
# Turn a general-purpose OS into a receiver appliance.
#
# Each item here is a drift the hand-built receiver had: no persistent journal,
# so its three-hourly reboots were undebuggable; no firewall despite ufw being
# installed; and a */5 cron re-running iwconfig because NetworkManager kept
# putting wifi power-save back.
set -euo pipefail

echo "hostname -> $HOSTNAME"
hostnamectl set-hostname "$HOSTNAME"
# 127.0.1.1 must track the hostname or sudo warns on every invocation.
if grep -q '^127\.0\.1\.1' /etc/hosts; then
  sed -i "s/^127\.0\.1\.1.*/127.0.1.1\t$HOSTNAME/" /etc/hosts
else
  printf '127.0.1.1\t%s\n' "$HOSTNAME" >>/etc/hosts
fi

apt-get update -qq
DEBIAN_FRONTEND=noninteractive apt-get install -y -qq \
  avahi-daemon ufw unattended-upgrades bc curl

# Persistent journal. Without this, logs live in /run and vanish on reboot —
# which is precisely when you want them.
mkdir -p /etc/systemd/journald.conf.d
cat >/etc/systemd/journald.conf.d/boxradar.conf <<'EOF'
[Journal]
Storage=persistent
SystemMaxUse=200M
EOF
mkdir -p /var/log/journal
systemd-tmpfiles --create --prefix /var/log/journal >/dev/null 2>&1 || true
systemctl restart systemd-journald

# Wifi power-save off, via NetworkManager rather than a cron that fights it.
# 2 = disable.
mkdir -p /etc/NetworkManager/conf.d
cat >/etc/NetworkManager/conf.d/boxradar-wifi-powersave.conf <<'EOF'
[connection]
wifi.powersave = 2
EOF

# Swap. Raspberry Pi OS defaults to 100MB, which is not enough headroom for
# the 367MB peak when the configuration UI reduces a coastline for a new area.
# 512MB costs nothing on an 8GB+ card and keeps a 1GB board off the OOM killer
# during the one step that needs the memory.
if [[ -e /etc/dphys-swapfile ]]; then
  current=$(awk -F= '/^CONF_SWAPSIZE/ {print $2}' /etc/dphys-swapfile)
  if [[ ${current:-0} -lt 512 ]]; then
    echo "swap ${current:-0}MB -> 512MB"
    sed -i 's/^CONF_SWAPSIZE=.*/CONF_SWAPSIZE=512/' /etc/dphys-swapfile
    grep -q '^CONF_SWAPSIZE' /etc/dphys-swapfile || \
      echo 'CONF_SWAPSIZE=512' >>/etc/dphys-swapfile
    systemctl restart dphys-swapfile
  else
    echo "swap already ${current}MB"
  fi
fi

# Any inherited reboot cron is removed. A receiver that reboots on a timer is
# hiding a fault, not fixing one.
if crontab -l 2>/dev/null | grep -q 'shutdown -r'; then
  echo "removing a scheduled reboot from root's crontab"
  crontab -l 2>/dev/null | grep -v 'shutdown -r' | crontab -
fi

echo "configuring ufw"
ufw --force reset >/dev/null
ufw default deny incoming >/dev/null
ufw default allow outgoing >/dev/null
for port in 22 80 8081 8082 8754; do ufw allow "$port/tcp" >/dev/null; done
# tar1090's optional second instance. Only opened if it is configured.
if [[ -e /etc/lighttpd/conf-enabled/95-tar1090-otherport.conf ]]; then
  ufw allow 8504/tcp >/dev/null
fi
ufw --force enable >/dev/null
echo "ufw: $(ufw status | head -1)"

# Security updates only. This box may be in a house you cannot reach.
cat >/etc/apt/apt.conf.d/51boxradar-unattended <<'EOF'
Unattended-Upgrade::Origins-Pattern {
        "origin=Debian,codename=${distro_codename},label=Debian-Security";
        "origin=Raspbian,codename=${distro_codename},label=Raspbian";
};
Unattended-Upgrade::Automatic-Reboot "false";
EOF
cat >/etc/apt/apt.conf.d/20auto-upgrades <<'EOF'
APT::Periodic::Update-Package-Lists "1";
APT::Periodic::Unattended-Upgrade "1";
EOF
systemctl enable --now unattended-upgrades >/dev/null

if [[ -n ${STATIC_IP:-} ]]; then
  conn="$(nmcli -t -f NAME connection show --active | head -1)"
  echo "setting static IP $STATIC_IP on '$conn'"
  nmcli connection modify "$conn" ipv4.method manual ipv4.addresses "$STATIC_IP"
  echo "NOTE: the address changes on the next reboot or reconnect."
fi

echo "os: hostname=$HOSTNAME, journal persistent, ufw enabled"
```

Provisions a BOXRADAR receiver from a bare Raspberry Pi OS Lite install:
readsb, tar1090, the ADSBExchange and Flightradar24 feeders, and the
`boxradar-site` / `boxradar-config` services.

Runs on the **receiver Pi**. Not the display, not a server.

- Raspberry Pi with **64-bit** Raspberry Pi OS Lite (Bookworm), **≥1GB RAM**
  (2GB recommended — the first coastline build for a new area peaks at 367MB)
- An RTL-SDR dongle, connected
- Wifi already configured and SSH reachable — use Raspberry Pi Imager's

- A Flightradar24 sharing key

built for ARMv7 and will not execute.

```bash
git clone <repo> && cd boxradar/tools/receiver-install
sudo ./install.sh
```

The first run asks for the site's position, aerial height, nearest METAR
airport and feeder credentials, writes them to `/etc/boxradar/receiver.conf`,
then installs everything. Expect 20–30 minutes, most of it readsb compiling.

| Flag | Effect |
|---|---|
| `--check` | Render every config and diff against what is live. Changes nothing. |
| `--from N` | Resume at stage N |
| `--force` | Re-run stages already marked complete |
| `--no-wizard` | Use `receiver.conf` as-is, prompt for nothing |

If a stage fails, fix the cause and re-run — completed stages are skipped.
The full log is at `/var/log/boxradar-install.log`, with secrets redacted; it
is the right thing to send when asking for help.

## After installing

The receiver works immediately, but **the display shows no map** until one is
published. Open `http://<box>:8082/`, choose the controlled airspace that
matters locally, and publish. That step needs local knowledge, so it is not
automated.

## Rebuild runbook

Not code — the sequence to follow once the tasks above are complete. Step 1 is
the one with no undo.

- [ ] **1. Back up, and verify the backup restores.**

```bash
mkdir -p ~/backups/boxradar-pi-$(date +%F) && cd $_
ssh pi@192.0.2.10 'sudo cat /etc/fr24feed.ini' > fr24feed.ini
ssh pi@192.0.2.10 'sudo cat /usr/local/share/adsbexchange/adsbx-uuid' > adsbx-uuid
ssh pi@192.0.2.10 'sudo cat /var/lib/private/boxradar-config/selection.json' > selection.json
ssh pi@192.0.2.10 'sudo cat /etc/boxradar-site/config.json' > config.json
ssh pi@192.0.2.10 'sudo cat /etc/default/readsb' > readsb.default
scp pi@192.0.2.10:/var/www/html/site.bin .
# Full card image — the only real rollback, and it captures anything forgotten.
ssh pi@192.0.2.10 'sudo dd if=/dev/mmcblk0 bs=4M status=progress' \
  | gzip > card.img.gz
```

Verify before erasing anything: every file non-empty, `gzip -t card.img.gz`
passes, and `site.bin` is 17148 bytes.

- [ ] **2. Flash Raspberry Pi OS Lite 64-bit**, pre-seeding wifi, SSH, user and
  hostname in Raspberry Pi Imager's advanced options.

- [ ] **3. Clone the repo and run the installer**, restoring `ADSBX_UUID` and
  `FR24_KEY` from the backup at the prompts.

- [ ] **4. Republish the map.** Copy `selection.json` back into
  `/var/lib/private/boxradar-config/`, restart `boxradar-config`, then publish
  from the UI. The coastline is refetched and reduced — this is the 367MB,
  ~30-second step.

- [ ] **5. Confirm the board.** It picks up the new `site.bin` on its next
  geography poll. Check the datablocks, the map, and that the MLAT count in
  brackets is non-zero after a few minutes.

- [ ] **6. Only then discard the card image** — it is the last copy of AirHits.

## Second unit

Same installer, his own answers. He needs: the repo, his FR24 key from you, a
flashed card with his wifi pre-seeded, and his position and aerial height.
After `install.sh` completes he opens `http://<box>:8082/` and authors his own
map — which is the part that cannot be shipped to him, because which airspace
matters is local knowledge.
